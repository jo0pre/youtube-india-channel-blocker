# YouTube India Channel Blocker

A Google Chrome extension that automatically detects and hides YouTube channels based in India from your feed.

## Features
* Scans video metadata on home, search, and recommendation feeds.
* Hides content from channels located in India automatically.

## How to Install Manually
1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select this folder.
